## 修复

- vinext 0.0.50 在 Windows 将静态资源缓存键写成反斜杠路径；`npm run start` 现在启动前执行精确版本兼容补丁。在目录遍历处统一 URL 分隔符，覆盖压缩变体及 `.vite` 排除；重复执行不改变结果。Linux 不打补丁。
- 手机自动高度容器中的 SVG 原为 `height:0;flex:1 1 0`，实测高度为 0；移动布局现在给主图明确高度。
- 全屏 API 被拒绝时启用页面内全屏；退出按钮与 Escape 可退出已有回退布局。
- 蜡烛图加入已有绘图区裁剪规则，不钳制每根蜡烛的 X 坐标。
- 移除图例里的 `$old` 残留文本。
