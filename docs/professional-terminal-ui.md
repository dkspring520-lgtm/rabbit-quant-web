## 已实现

- 修改现有专业操盘台 `/?code=601899`，保留 `/rabbit-studio` 的已有跳转。无需重建登录、账户、策略或行情请求。
- 40px 顶栏与 40px 左工具栏，34px 股票监控条，42px 紧凑行情条。
- 中部自适应图表，右侧默认 320px 盘口，保留面板拖动/折叠。
- 右侧“行情 / 盘口”和“双兔策略 / 执行”切换，复用原有完整决策与执行内容。
- 十档报价直接读取采集器已有 bidPrices / askPrices / bidVolumes / askVolumes。缺失档位保持空值，数量以股为单位。
- 逐笔列表使用采集器最近 80 笔原始成交，时间明确为采集接收时间。仅添加返回字段，没有改变交易或信号计算。
- 原有主力追踪和订单流影子面板移到图表底部；保留各自数据与解释。
- 复用原有 SVG 分钟 K 线、量柱、VWAP、低吸/止盈信号、缩放、拖动和十字光标。K 线按实际价格范围缩放；分时保留昨收中心轴。
- 多股监控、策略、回测和原有指标计算继续使用原实现；本阶段没有重写 MA / KDJ 或策略引擎。
- 窄屏改为图表与盘口上下排列，局部工具条可滚动。

## 验证与边界

- 使用 `npx next dev --webpack -p 3000` 启动并实际打开页面。
- 验证切换股票、分时/1mK、盘口/逐笔、策略页面、键盘十字光标。真实公开行情显示 242 根分钟 K 线。
- 390px 窄屏未出现页面横向溢出。
- 10 项针对盘口空值/部分档位/延迟、原有行情轴、VWAP 与 studio 跳转的测试通过。
- 本机未连接 L2 采集服务；真实十档与逐笔端到端需要运行更新后的采集器。有数据和延迟状态通过组件测试覆盖，没有将测试报价注入实际页面。
- 默认 `npm run dev` 的 Vite/Cloudflare 环境报 `node:async_hooks` 兼容错误，因此本次使用项目已有 Next 开发运行方式。
- 仓库整体 TypeScript 检查仍有原有错误（包括技能样例依赖、旧类型声明和已删除路由的生成类型）；新盘口组件未报告类型错误。
- 旧 crosshair 测试中三项依赖旧代码文本匹配而失败；真实键盘十字光标检查通过。未为使文本断言通过而回退现有缩放/拖动实现。
- 仅完成本地代码与运行验证，未部署线上。
